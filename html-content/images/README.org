* Tucson Sonoran Desert Garden Calendar — image archive

Unpack this archive next to tucson_sonoran_garden_calendar_v2.org. The archive
contains an images/ directory used by the Org file.

The Org file contains source/credit information for every image. Some images are
crops from source PDFs; these are included for convenient local identification.
